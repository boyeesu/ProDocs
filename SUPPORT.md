# Support

ProDocs `0.2.x` is a production-ready beta for local repository indexing,
generated documentation, freshness checks, and scoped agent context.

## Where to ask

- Usage questions and ideas: [GitHub Discussions](https://github.com/boyeesu/ProDocs/discussions)
- Reproducible defects: [GitHub Issues](https://github.com/boyeesu/ProDocs/issues)
- Security vulnerabilities: [private vulnerability reporting](https://github.com/boyeesu/ProDocs/security/advisories/new)

Include the ProDocs version, Node.js version, operating system, command, relevant
configuration, and a minimal repository or fixture when possible. Remove
secrets and proprietary source before posting publicly.

## Service targets

This open-source project provides best-effort support, not a commercial SLA.
Maintainers target:

- acknowledgement of private security reports within seven days;
- initial triage of high-impact reproducible defects within seven days;
- compatibility fixes in the next patch when no safe workaround exists.

The latest minor release receives security and correctness fixes. Older minors
may be asked to upgrade before investigation.
